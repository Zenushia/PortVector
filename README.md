## 🚀 About The Project
**PortVector** is a lightweight and interactive command-line interface (CLI) tool designed to scan common network ports on a target IP address or domain. Built using Python's native `socket` library, it helps network engineers and developers quickly audit infrastructure and check service accessibility.

## ✨ Features
- 🎯 **Interactive Target Input:** Dynamically scan any custom IP address or domain (e.g., `127.0.0.1` or target domains).
- 🔌 **Common Service Mapping:** Automatically checks critical ports such as HTTP, HTTPS, SSH, FTP, DNS, and MySQL.
- 🟢🔴 **Real-Time Status Detection:** Instantly identifies whether a port is `OPEN 🟢`, `CLOSED 🔴`, or `FILTERED ⚠️`.
- 📦 **Zero Dependencies:** Powered entirely by standard Python 3 libraries (`socket`, `time`).
